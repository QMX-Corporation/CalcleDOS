# Security Policy

## Supported Versions
Security updates and patches are exclusively provided for the latest stable release of CalcleDOS.

| Version | Supported          |
| ------- | ------------------ |
| v0.0.x  | :white_check_mark: |
| < 0.0.1 | :x:                |

## Reporting a Vulnerability

The QMX Corporation team and the project BDFL take security vulnerabilities very seriously. If you discover a security flaw or vulnerability within CalcleDOS (including low-level components, memory handling, or build pipelines), **please do not disclose it publicly** on GitHub Issues, Discussions, or social media until it has been officially addressed.

Instead, please report it privately via email:

* **Email:** `joaoanandalima@gmail.com`
* **Recipient:** `dev12124` (BDFL)

### What to Include in Your Report
To help us triage and resolve the issue as quickly as possible, please provide:
* A detailed description of the vulnerability and its potential impact.
* Steps, proof-of-concept code, or configuration details required to reproduce the issue.
* Affected target platforms (Windows, macOS, Linux, Android, Unix) or components.

### Our Response Process
1. **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
2. **Investigation:** The BDFL and core maintainers will investigate the issue and verify its impact.
3. **Patch & Disclosure:** Once a fix is prepared, we will coordinate a responsible public disclosure and release an updated version of CalcleDOS.
