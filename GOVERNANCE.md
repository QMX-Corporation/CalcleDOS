# CalcleDOS Governance

## 1. Introduction
CalcleDOS is an open-source project dedicated to delivering a high-performance interactive calculator equipped with AI chatbot capabilities and a graphical interface. To ensure the project maintains its technical vision, architectural integrity, and uncompromising code quality, CalcleDOS operates under a Benevolent Dictator For Life (BDFL) governance model.

## 3. Decision-Making Process
* **Day-to-Day Contributions:** Maintainers and contributors propose changes via Pull Requests. Automated continuous integration (CI/CD) pipelines, syntax checkers (`checkpatch.pl`), and code reviews handle initial vetting.
* **Core Decisions:** Major architectural changes, breaking updates, or additions to core low-level components (such as UEFI, OS-level hooks, or core compiler/linker configurations) require explicit review and approval by the BDFL.

## 4. Maintainers and Elevation
Becoming a maintainer requires meeting rigorous technical standards outlined in the project documentation (`CONTRIBUTORS.md`), demonstrating mastery in low-level systems, theory of computation, and adherence to the project's strict engineering ethos.
