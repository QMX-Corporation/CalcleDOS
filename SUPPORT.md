# Support

Thank you for using CalcleDOS! If you encounter issues, have questions, or need assistance, please utilize the appropriate channels below.

## Getting Help

### 1. GitHub Discussions (Recommended for Qatives & Q&A)
For general questions, architectural discussions, feature ideas, or community support, please use the **GitHub Discussions** tab in the QMX Corporation repository. Avoid opening GitHub Issues for questions or support requests.

### 2. GitHub Issues (For Bugs and Feature Requests)
If you encounter a verified bug or wish to propose a specific new feature for CalcleDOS:
* Check existing open and closed issues to avoid duplicates.
* Use the provided `.github/ISSUE_TEMPLATE/` (Bug Report or Feature Request) to structure your submission clearly.

### 3. Security Vulnerabilities
If you discover a security vulnerability within CalcleDOS, please **do not** open a public issue or discussion. Refer to our `SECURITY.md` file for private reporting instructions.

## Scope of Support
CalcleDOS is an open-source project driven by community contributions and guided by the BDFL. Support is provided on a best-effort basis by maintainers and contributors who meet our technical standards.
